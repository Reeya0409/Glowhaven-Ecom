# 🌸 GlowHaven – Cosmetic E-Commerce Website

GlowHaven is a fully functional cosmetic e-commerce website built using HTML, CSS, and PHP.  
Users can browse products, add items to cart, and place orders.

---

## 🚀 Features

- User Registration & Login
- Product Listing Page
- Add to Cart Functionality
- Checkout System
- Admin Panel (Add / Manage Products)
- Responsive Design

---

## 🛠 Tech Stack

- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: PHP
- Database: MySQL
- Server: XAMPP

---

## 📁 Project Structure

- `admin_area/` – Admin panel for managing products & orders  
- `users_area/` – User authentication system  
- `include/` – Database connection & reusable PHP components  
- `functions/` – Business logic (cart, products, etc.)  
- `database/` – MySQL database file  
- `images/` – Product images  
- `demo images/` – Screenshots for README  
- `fontawesome-free-6.4.0-web/` – Font Awesome icons  

### Main Pages
- `index.php`
- `display_all.php`
- `product_details.php`
- `search_product.php`
- `cart.php`
- `contact.php`
- `style.css`

---

## 🗄 Database Setup

1. Open phpMyAdmin
2. Create a new database named `store`
3. Import `store.sql`
4. Update database credentials in `config.php`

---

## 💻 How to Run

1. Install XAMPP
2. Place project folder inside `htdocs`
3. Start Apache & MySQL
4. Open browser:
   http://localhost/glowhaven-ecommerce-php
